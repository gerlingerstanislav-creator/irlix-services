# 07 — Public methodology references (attribution and practical scope)

Use principles rather than copy protected texts. These links are references, not substitute acceptance criteria; a project-specific contract governs expected behavior.

- ISTQB CTFL v4.0.1 (official): https://istqb.org/wp-content/uploads/2024/11/ISTQB_CTFL_Syllabus_v4.0.1.pdf — static reviews, risk-based testing, equivalence partitioning, boundary values, decision tables, state transition, exploratory testing, coverage concepts.
- OWASP Web Security Testing Guide, authorization: https://owasp.github.io/www-project-web-security-testing-guide/stable/4-Web_Application_Security_Testing/05-Authorization_Testing/04-Testing_for_Insecure_Direct_Object_References — ownership and direct object references; adapt safely for authorized test accounts.
- OWASP API Security Top 10: https://owasp.org/API-Security/ — API-specific risk taxonomy including object/function authorization, business flows, inventory.
- OWASP Application Security Verification Standard (ASVS): https://owasp.org/www-project-application-security-verification-standard/ — verifiable secure-design categories; choose the appropriate version and scope for project.
- W3C WCAG 2.2: https://www.w3.org/TR/WCAG22/ — accessibility reference for applicable interfaces; automated scans alone are insufficient.
- Pact documentation: https://docs.pact.io/ — consumer/provider contract test ideas; contract testing is not a replacement for provider business logic tests.
- Practical Test Pyramid: https://martinfowler.com/articles/practical-test-pyramid.html — confidence by granularity, integration boundaries, avoid duplicative slow end-to-end suites.
- OpenAI Skills in ChatGPT: https://help.openai.com/en/articles/20001066-skills-in-chatgpt — official import/create workflow.
- OpenAI Skills package structure: https://developers.openai.com/api/docs/guides/tools-skills — SKILL.md, scripts, assets, references.

**Scope caution:** Standards and guides evolve. Check the latest official version if a specific compliance claim or formal audit is requested. This skill makes no claim of certification or fully compliant security audit.
