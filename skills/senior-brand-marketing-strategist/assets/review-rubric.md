# Brand strategy quality and release rubric

Score 0 (absent), 1 (partial), 2 (evidenced) per criterion. This is **not customer research**; the sum is an internal review device.

| Criterion | Pass evidence | Stop condition |
|---|---|---|
| Target | Named decision-maker and relevant job | Generic "everyone" |
| Category | Credible alternatives incl. in-house/inertia | Imaginary category |
| Differentiation | Specific and meaningfully hard to copy | "quality/innovation" only |
| RTB | Source, mechanism and permission to use | Fabricated proof |
| Consistency | Sales, HR, product message no contradictions | Conflicting promises |
| Voice | Observable Do/Don't examples | Generic adjectives |
| Identity continuity | Mark change or NO CHANGE supported by side-by-side test | New mark only for novelty |
| Rights/privacy | Provenance, consent, licence, no sensitive publication | PII or unlicensed art in release |
| Practical use | Tested across web/print/small/mono | Moodboard only |
| Governance | Named owner, status, version and approval record | Unknown authorisation |

Suggested interpretation: 17–20 well supported → ready for owner review; 12–16 → conditional revision; 0–11 → rework. **Never override a stop condition with a high score.** Mark actual tests PASS/FAIL/NOT TESTED; no synthetic interviews or metrics.

## Brand-review handoff

- Recommendation: KEEP / EVOLVE / REPLACE with rationale.
- Strength of evidence: high / medium / low with dated references.
- Competing hypothesis and reason not chosen.
- Risk/rights blockers (if any).
- Approval requested and what remains unverified.
- Next smallest test; not an invented launch KPI.
