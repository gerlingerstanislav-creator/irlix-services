# Evidence-based sources and when to consult

Use current primary guidance; verify version/date when the task involves certification or platform releases. These are starting points, not substitutes for project design-system rules.

- W3C WCAG 2.2 normative recommendation and quick reference: https://www.w3.org/TR/WCAG22/ and https://www.w3.org/WAI/WCAG22/quickref/ — definitions of success criteria; check target/contrast/reflow exceptions.
- W3C WAI-ARIA Authoring Practices Guide: https://www.w3.org/WAI/ARIA/apg/patterns/ — keyboard and semantics for complex widgets such as grid, tabs, dialog and combobox.
- WCAG SC 2.5.8 Target Size (Minimum), AA: https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum — 24×24 CSS px baseline with specified exceptions; not equivalent to mobile comfort target.
- WCAG 1.4.3 Contrast (Minimum): https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html — text contrast thresholds with defined exceptions.
- Nielsen Norman Group, Ten Usability Heuristics (reviewed 2024): https://www.nngroup.com/articles/ten-usability-heuristics/ — diagnostic heuristics, not empirical proof.
- Nielsen Norman Group, How Many Test Users in a Usability Study?: https://www.nngroup.com/articles/how-many-test-users/ — qualitative sample guidance and caveats.
- Apple Human Interface Guidelines (Accessibility): https://developer.apple.com/design/human-interface-guidelines/accessibility — iOS/iPadOS/macOS interaction and accessibility considerations; platform-specific, not web law.
- Apple HIG design principles: https://developer.apple.com/design/human-interface-guidelines/design-principles — consistency, adaptation, flexible input.
- Material Design: https://m3.material.io/ — useful Android/adaptive patterns when aligned with project, never auto-impose Material styles.
- Android accessibility principles: https://developer.android.com/guide/topics/ui/accessibility — native semantics, touch, text scaling and services.

If sources conflict, make scope/authority/version explicit. A design guideline is not the same as a WCAG success criterion and neither is automatically a legal requirement in every jurisdiction.
