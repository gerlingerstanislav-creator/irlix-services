# Передача контекста и возобновление — указатель

Единственный протокол поручения/возврата и независимости review — [DELEGATION](agent/DELEGATION.md#поручение-и-возврат).

Сохранение активной задачи, PR/checkpoint и алгоритм продолжения — [STATE](agent/STATE.md). Это разные механизмы: handoff помощнику не заменяет долговременное состояние задачи.

Передавать цель, принятые решения и проверяемые факты; не копировать весь чат или авторскую самооценку в независимый review. Доступ к общему Git не означает технической изоляции контекстов.

Пользовательские сообщения регулирует [WORKFLOW](agent/WORKFLOW.md#6-общение-блокеры-продолжение). Обязательных масок `[PM]`/`[QA]`, таймеров и отдельного сообщения на каждую смену компетенции нет.
