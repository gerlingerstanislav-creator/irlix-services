# Timesheets — точечный вход

- Реализация: `apps/timesheets/`, `services/timesheets/`.
- Продукт: `ideas/company-internal-services-81-2.4/services/timesheets/`.
- Локальные стили календаря/матрицы: только экран, применяемые UI-компоненты и целевой тест.
- Изменение записи времени: модель записи, даты, часы, ограничения, подтверждение и покрывающие тесты.
- Привязка к проекту/сотруднику: читать **конкретный** контракт активных подключений Clients, Employees — только для идентификаторов.
- Отсутствия: читать только контракт поставки данных Vacations, не процесс согласования.
- Миграция исторических данных: дополнительно `docs/MIGRATION.md`, код соответствующего маппинга, сверка ошибок/rollback. Не изучать все типы миграций.

Проверять текущую модель по реализации; индекс не фиксирует схему и не заменяет ТЗ.
