# Навигация по проектному контексту

[MATRIX](MATRIX.md) — источники технических знаний; [MANIFEST](MANIFEST.json) — пути и прямые контракты; [CONTEXT_SCOPE](../CONTEXT_SCOPE.md) — границы чтения. Индексы сервисов указывают на разделы, не заменяют требования и не являются обязательным пакетом.

Процесс работы агента находится отдельно: [WORKFLOW](../agent/WORKFLOW.md), [BEHAVIORS](../agent/BEHAVIORS.md), [STATE](../agent/STATE.md). Автоматические подсказки по путям не определяют намерение, риск или достаточность проверки.
