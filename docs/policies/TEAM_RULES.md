# Правила исполнения задач — указатель

Обязательный минимум — [AGENTS](../../AGENTS.md), процесс — [WORKFLOW](../agent/WORKFLOW.md), подключение компетенций — [BEHAVIORS](../agent/BEHAVIORS.md).

Роли не образуют обязательную очередь. [DELEGATION](../agent/DELEGATION.md) определяет необходимость независимого исполнителя, передачу контекста, реальные возможности, повторный review и запрет конкурирующей записи. Кастомные Skills отключены по [AGENT_SKILLS](../AGENT_SKILLS.md).

Для code review сохраняются технические инварианты: владение данными сервисом; проверки permission + scope, переходов и периодов при их изменении; shared UI через @irlix/ui; визуальный PASS только с реальным evidence. Полные условия проверки — [verification](../agent/behaviors/verification.md) и затронутые горизонтали.

Продолжение и общий checkpoint — [STATE](../agent/STATE.md); результат — [REPORTING](../REPORTING.md). Оценки сроков, прогнозы длительности и обязательный учёт времени приостановлены; новые таймеры/ритуальные отчёты не вводятся.
