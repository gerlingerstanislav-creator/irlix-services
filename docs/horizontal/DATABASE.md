# DATABASE — IRLIX Services

Канонический горизонтальный регламент, выделенный из `docs/policies/ENGINEERING.md` без изменения смысла. Подключать лишь для соответствующего технического scope; полное чтение всех горизонталей не требуется.

## Правила разработки

- Прямое чтение или изменение таблиц другого сервиса запрещено.

- На первом этапе допускается одна физическая PostgreSQL, но каждый сервис владеет своей schema и работает через отдельного DB user.
