# Маршрутизатор контекста — совместимость

**Не загружать этот файл вместе с матрицей как второй обязательный регламент.** Актуальный алгоритм — [MATRIX.md](context/MATRIX.md); канонические координаты и путь к документу — [MANIFEST.json](context/MANIFEST.json). Юридические/технические ограничения и Git-правила сохраняются в [AGENTS.md](../AGENTS.md) и соответствующих регламентах.

## Алгоритм (перед первым чтением большого документа)

Тип задачи → затронутая вертикаль → горизонталь по фактическому коду → **конкретный сценарий/раздел**. Сначала поиск пути, заголовка или символа, потом адресное чтение. Не загружать всю вертикаль, все горизонтали и историю задач.

## Уровни чтения

L0 — инварианты `AGENTS.md`; L1 — целевой код/сценарий; L2 — затронутый контракт; L3 — системный аудит по реальному scope. Подробности — [матрица](context/MATRIX.md).

## Режимы работы (не меняют требований Git/CI/QA)

Fast — локальные UI/copy/docs; Standard — локальная логика и API; Deep — миграция, security, межсервисные и архитектурные задачи. Уровни не отменяют тесты, безопасность и подтверждение изменений.

## Что читать по триггеру

См. [таблицу горизонталей](context/MATRIX.md#логические-горизонтали-не-дублировать-правила) и [индексы сервисов](context/README.md). Для PR/CI/deploy отдельно действуют [GIT_RELEASE](policies/GIT_RELEASE.md) и [CI](CI.md).

## Проверка экономии контекста

Протокол сценариев и ограничения измерения — [VALIDATION.md](context/VALIDATION.md). Не заявлять снижение токенов без фактического замера.
