# Исполнители задач IRLIX Services

Каноническая система: [WORKFLOW](agent/WORKFLOW.md), [подключаемое поведение](agent/BEHAVIORS.md), [делегирование](agent/DELEGATION.md), [состояние задачи](agent/STATE.md).

Ведущий отвечает за весь результат. Компетенции выбираются по цели, неопределённости, влиянию и рискам; отдельные помощники — по независимости проверки и полезному параллелизму. Название интерфейса Chat/Work не выбирает другой процесс и не является основанием остановки.

Профили `.github/agents/` — короткие адаптеры к модулям для реально назначенного исполнителя. Назначать все роли на любую задачу запрещено. Точные правила самостоятельной работы при недоступном делегировании, обязательного review существенных изменений и truthful evidence — в DELEGATION.

`.github/workflows/ai-team.yml` выводит только подсказки по diff. Это НЕ AI-review и НЕ подтверждение тестирования. Он не запускает модель, не заменяет оценку задачи и не гарантирует доступ к ideas/инструментам. Production разрешается только по [release-регламенту](policies/GIT_RELEASE.md).

Кастомные Skills остаются отключены: [AGENT_SKILLS](AGENT_SKILLS.md). Политика моделей находится только в DELEGATION; названия в профиле не переключают модель автоматически.
