# Documentation index

Перед работой читать `/AGENTS.md` и `CONTEXT_SCOPE.md`, затем выбирать документы по текущему сервису и задаче. Этот индекс не требует загрузки всех перечисленных документов или ТЗ остальных сервисов.

- `CONTEXT_SCOPE.md` — обязательные границы рабочего контекста, пути сервисов и правила чтения контрактов соседей.
- `ARCHITECTURE.md` — фактическая архитектура реализации.
- `DEVELOPMENT.md` — локальная разработка.
- `DEPLOYMENT.md` — устройство стенда и CI/CD.
- `QA.md` — тестирующий агент, автоматизация, отчёты и ограничения покрытия.
- `STATUS.md` — текущее состояние итерации.
- `/AGENTS.md` — обязательные правила работы с проектом.

Полная продуктовая документация и ТЗ находятся в репозитории `ideas/company-internal-services-*`.


- [AI-команда и общение ролей](AI_TEAM.md) — последовательные роли одного чата, параллельные задачи в отдельных ветках и QA через GitHub Actions.
