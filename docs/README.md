# Documentation index

Перед работой читать `/AGENTS.md` и `CONTEXT_SCOPE.md`, затем выбирать документы по текущему сервису и задаче. Этот индекс не требует загрузки всех перечисленных документов или ТЗ остальных сервисов.

- `CONTEXT_SCOPE.md` — обязательные границы рабочего контекста, пути сервисов и правила чтения контрактов соседей.
- `horizontal/` — канонические инженерные правила по компетенциям, не загружать целиком; `policies/ENGINEERING.md` сохраняет ссылки на старые разделы.
- `context/VALIDATION.md` — статическая проверка полноты переноса и трёх тестовых маршрутов.
- `context/MATRIX.md` — логическая сетка горизонтальных компетенций и вертикальных сервисов; `context/MANIFEST.json` — машинно-читаемые маршруты; `context/AUDIT_2026_10_24.md` — инвентаризация дублирования.
- `ARCHITECTURE.md` — фактическая архитектура реализации.
- `DEVELOPMENT.md` — локальная разработка.
- `DEPLOYMENT.md` — устройство стенда и CI/CD.
- `QA.md` — тестирующий агент, автоматизация, отчёты и ограничения покрытия.
- `CONTINUOUS_IMPROVEMENT.md` — постоянное улучшение процесса (Kaizen/PDCA), инициативы ведущего без лишней бюрократии.
- `STATUS.md` — текущее состояние итерации.
- `/AGENTS.md` — обязательные правила работы с проектом.

Полная продуктовая документация и ТЗ находятся в репозитории `ideas/company-internal-services-*`.


- [Переносимые полные Skills в Git](../skills/README.md) — импорт ZIP с references, scripts, assets и тестами, SHA256-проверка.
- [Подключение профессиональных Skills к ролям](AGENT_SKILLS.md) — отключённые пакеты и условия отдельного возобновления.
- [AI-команда и общение ролей](AI_TEAM.md) — совместимость профилей с адаптивным workflow и реальными возможностями среды.
- [Протокол передачи контекстов между ролями](AGENT_CONTEXT_PROTOCOL.md) — кто какие документы получает, независимый аудит и видимые отметки этапов.
- [Инженерные правила](policies/ENGINEERING.md), [Git и релизы](policies/GIT_RELEASE.md), [Issues](policies/ISSUES.md), [обязательные правила AI-команды](policies/TEAM_RULES.md) — детальные политики, вынесенные из корневого AGENTS.md без потери требований.
