# Статус профессиональных кастомных Skills

**Отключены с 24.10.2026.** Не назначать, не загружать и не применять профессиональные кастомные Skills из `skills/` или персонального ChatGPT при обычном выполнении задач IRLIX Services. Чтение/редактирование самих Skills допускается как объект явно порученного аудита или сопровождения; это не их активация.

Рабочее поведение самодостаточно описано в [BEHAVIORS](agent/BEHAVIORS.md). Для возобновления Skills нужно отдельное решение владельца и проверка конфликтов/пользы. Новая система инструкций сама по себе не снимает отключение.

## Сохранённые пакеты — инвентарь, не команда подключения

| Компетенция | Пакет в skills/ |
|---|---|
| Analysis | senior-business-system-analyst |
| UI/UX | senior-product-uiux-designer |
| Backend | senior-php-laravel-backend-engineer |
| Frontend | senior-javascript-vue-frontend-engineer |
| Verification | senior-qa-engineer |
| Data | senior-database-engineer |
| Security | senior-application-security-engineer |

Имя пакета или ссылка не доказывают установку/прочтение. Репозиторный пакет не устанавливает навык в личном аккаунте; доступность в одной сессии не гарантирует доступность у помощника. Skills не запускают AI самостоятельно и не переопределяют полномочия, принятые требования, security/Git/CI или конечную точку задачи. После возможного включения источники и версии должны быть явно определены; при недоступности продолжать по самодостаточным репозиторным инструкциям без фиктивного статуса использования.
