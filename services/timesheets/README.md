# Timesheets backend

Laravel-сервис учёта коммерческого рабочего времени.

MVP поддерживает ввод часов по активным подключениям Clients, предварительное подтверждение сотрудником, финальное подтверждение руководителем/аккаунтом, редактирование из управления, блокировку периода, аудит и аналитику коммерческой загрузки.

Интеграции выполняются только через API Employees, Clients и Vacations. Timesheets владеет своей PostgreSQL schema `timesheets`.

При изменении записей, подтверждений сотрудника или финальных подтверждений Timesheets проверяет статус соответствующего отчётного периода в Clients. После перехода в «ТШ на согласовании» записи периода заблокированы; откат в «Новый» снимает блокировку. Роль `platform-admin` читается из Employees `/access/me` и даёт полный обзор всех сотрудников и проектов на странице управления.

На странице управления матрица разделена по специалисту и клиенту; двойной клик по дню открывает только проекты этой пары. Одна кнопка сохраняет все проекты клиента за день, закрывает окно и показывает уведомление. Стандартные фильтры включают специалиста и клиента. Ссылка `/timesheets/?section=management&month=YYYY-MM&client_id=ID&employee_id=ID` открывает управление с предустановленными фильтрами.

Для сотрудников Accounting справочник сотрудников читается через Employees `/clients-directory`; проекты ограничиваются теми клиентами, где текущий сотрудник назначен аккаунтом. Проверка редактирования каждой записи остаётся серверной.

На странице управления действие закрытия месяца убрано. Ранее закрытый месяц можно открыть уполномоченному пользователю; блокировка существующего закрытого периода и блокировка после отправки отчётного периода по-прежнему действуют.
