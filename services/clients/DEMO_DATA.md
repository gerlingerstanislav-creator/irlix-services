# Demo data policy — Clients

Demo data must be synthetic and must not be copied from screenshots, production systems, customer records, employee records or other real-world source data.

Rules:
- use clearly synthetic client, lead, contact and specialist names;
- use reserved test domains such as `example.test` for email addresses;
- use synthetic phone numbers and identifiers;
- values such as rates, amounts and dates are illustrative test values only;
- screenshots may be used to understand UI structure, states and workflows, but never as a source for concrete demo records.

The current Clients demo dataset intentionally prefixes user-visible people/entities with `Демо` / `Demo` where practical to make the distinction obvious during testing.
