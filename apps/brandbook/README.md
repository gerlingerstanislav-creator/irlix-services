# IRLIX Brandbook — публичный исследовательский frontend

Отдельный статический Vue-сервис `/brandbook/` со структурой корпоративного брендбука. В этой итерации публикуются **только сведения, уже находящиеся в открытых источниках**, с ссылками и датами проверки. Геометрия логотипа доступна как inline SVG на официальном сайте, но правила фирменного использования, палитра, шрифты и юридический мастер **не утверждены**; интерфейс показывает это явно. Приложение не является редактором/CMS, не использует API и не содержит закрытых материалов. Пока фирменные стандарты не утверждены, в HTML выставлен `robots: noindex, nofollow, noarchive` — **это не ограничение доступа**; после утверждения контентного состава решение об индексации пересматривается. Для клавиатуры предусмотрен переход к основному содержимому; копирование подписано как описание внешнего источника, а не официальная бренд-формулировка.

## Локальная разработка

`cd apps/brandbook && npm install && npm run dev`

Тесты: `npm test`. Сборка: `npm run build`.

## Источники и решения

Полная продуктовая спецификация находится в приватном `ideas/company-internal-services-81-2.4/services/brandbook/product/`. Специфика IRLIX, приватное исследование, реестр активов и вопросы — в `company/irlix/`. Не копировать приватные тексты в публичный репозиторий.

Сервис использует `UiAppShell` и `@irlix/ui`, не изменяет и не включает в себя `/design-system/`. Подготовлен для отдельного Docker image, Compose, CI и host nginx. Production rollout — по прямой команде владельца после подтверждения разрешённого доступа и контента.
