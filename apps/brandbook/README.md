# IRLIX Brandbook — Vue-фронтенд с согласованной цифровой основой v1.0

Отдельный статический Vue-сервис `/brandbook/` со структурой корпоративного брендбука. **Новое маркетинговое направление от 24.10.2026:** `AI-augmented, engineer-led`, главный заголовок «Инженерная разработка, усиленная ИИ.». Инициатор выбрал использование ИИ как заметный акцент **вместе с инженерным опытом, знанием технологий, безопасностью и ответственностью**. Статус — маркетинговое направление проекта, не гарантия того, что все специалисты уже обучены/используют AI или что на каждом проекте доказано ускорение. Сохраняем A+B+C и принцип «Сначала задача. Потом решение.» как вторичный, а не главный слоган. Операционные AI-процессы и новые AI-продуктовые услуги требуют фактического evidence gate. **24.10.2026 инициатор проекта утвердил цифровую основу v1.0**: исходные шесть контуров SVG и светлую адаптацию букв, Onest 400/700, digital-палитру и консервативные границы публичных материалов. Интерфейс различает проектно утверждённые правила, сведения из открытых источников и нерешённые вопросы. **24.10.2026 инициатор подтвердил права ООО «ИРЛИКС» на текущий веб-SVG и разрешил свободное скачивание трёх цифровых вариантов в публичном брендбуке.** Иные клиентские/HR материалы, печать, интеграция и production release не утверждены. Приложение не является редактором/CMS, не использует API и не содержит закрытых материалов. Библиотека `/brandbook/assets/` даёт три оригинальных SVG логотипа и пять редактируемых цифровых шаблонов. **На production все скачивания защищены серверным Employees gateway**, хотя исходный Vue-бандл сам не вызывает бизнес-API. Onest self-hosted из открытого пакета Fontsource (SIL OFL 1.1); не добавлять вручную бинарники из внутренних архивов. До выпуска проверенного полного пакета в HTML выставлен `robots: noindex, nofollow, noarchive` — **это не ограничение доступа**; после утверждения контентного состава решение об индексации пересматривается. Для клавиатуры предусмотрен переход к основному содержимому; копирование подписано как описание внешнего источника, а не официальная бренд-формулировка.

## Digital brandbook v2.0 — реализованные носители и ресурсы

В девяти публично читаемых разделах показаны: фирменный логотип на светлом/тёмном фоне; семантическая палитра и три контрастные комбинации; Onest 400/700 и цифровая типографическая шкала; графические правила; четыре редакционные пары «Говорим/Избегаем»; адаптивные композиции сайта, слайда 16:9 и титульной страницы КП.

Раздел `/brandbook/assets/` содержит **3 исходных owner-approved SVG логотипа**, **2 скачиваемых токен-файла CSS/JSON** и **5 новых редактируемых самостоятельных фирменных SVG-макетов**:
- `public/downloads/irlix-template-presentation-cover.svg` — титульный слайд 1600×900;
- `public/downloads/irlix-template-proposal-cover-a4.svg` — обложка предложения 794×1123;
- `public/downloads/irlix-template-social-square.svg` — квадратная публикация 1080×1080.
- `public/downloads/irlix-template-letterhead-a4.svg` — деловой бланк с заполнителями, 794×1123.
- `public/downloads/irlix-template-business-card.svg` — визитка с заполнителями, 1080×600.

В SVG-шаблонах сохранены исходные шесть путей знака; графика и тексты редактируемы в векторных приложениях. Для точной типографики нужен Onest на устройстве. **Это проектные демонстрационные композиции, не подписанные клиентские КП, юридические/печатные мастера и не PPTX/DOCX.**

Браузерная проверка включает анонимную выдачу файлов (HTTP/MIME), число исходных SVG paths и axe-core на 8 страницах; Node-тест проверяет векторный состав, целостность и текстовые контрасты. Написанный тест не считается PASS до завершения workflow на точном SHA.

## Печать цифровых правил

На каждой странице есть кнопка **«Печать раздела»**, запускающая системный диалог браузера. Правила `@media print` выводят только выбранный раздел брендбука, без бокового меню/верхней панели/поиска и служебных управляющих кнопок. Шрифты и фирменная иерархия сохраняются; повторное использование возможно для внутренних digital-документов. Автоматический Chromium проверяет print media (скрытие UI и ненулевую область контента).

**Ограничение:** browser print не является сертифицированным CMYK/Pantone или мастер-файлом типографии. Перед физическим тиражом нужны реальные требования типографии, утверждённые шрифты, вылеты, размер знака и цветопробы. Заполнитель реквизитов нельзя оставлять в реальном документе.

## Локальная разработка

`cd apps/brandbook && npm install && npm run dev`

Тесты: `npm test`. Сборка: `npm run build`.

## Источники и решения

Полная продуктовая спецификация находится в приватном `ideas/company-internal-services-81-2.4/services/brandbook/product/`. Специфика IRLIX, приватное исследование, реестр активов и вопросы — в `company/irlix/`. Не копировать приватные тексты в публичный репозиторий.

Сервис использует `UiAppShell` и `@irlix/ui`, не изменяет и не включает в себя `/design-system/`. Подготовлен для отдельного Docker image, Compose, CI и host nginx. Production rollout — по прямой команде владельца после проверки актуального CI, доступности и разрешённого контента. Разрешение на скачивание SVG не означает разрешение на сам rollout.

## Ограничение доступа

**Production:** `/brandbook/` теперь закрыт на стороне host nginx, включая вложенные страницы, скачиваемые SVG, CSS/JSON, JS и шрифты. Допуск: назначенная в Employees специальная роль `top-management` или платформенный суперпользователь `platform-admin`. Добавление/снятие участников — Employees → «Роли»; должности и оргструктура автоматически роль не присваивают. При первом переходе Portal проводит Keycloak OIDC и создаёт короткую зашифрованную HttpOnly-cookie через Employees. Каждая загрузка проходит актуальную серверную проверку. Без авторизации контент не выдаётся; `noindex` лишь ограничивает индексацию. Локальный Vite preview открыт только для QA и **не доказывает** безопасность prod nginx.
