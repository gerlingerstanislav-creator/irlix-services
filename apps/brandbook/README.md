# IRLIX Brandbook — Vue-фронтенд с согласованной цифровой основой v1.0

Отдельный статический Vue-сервис `/brandbook/` со структурой корпоративного брендбука. **24.10.2026 инициатор проекта утвердил цифровую основу v1.0**: исходные шесть контуров SVG и светлую адаптацию букв, Onest 400/700, digital-палитру и консервативные границы публичных материалов. Интерфейс различает проектно утверждённые правила, сведения из открытых источников и нерешённые вопросы. **24.10.2026 инициатор подтвердил права ООО «ИРЛИКС» на текущий веб-SVG и разрешил свободное скачивание трёх цифровых вариантов в публичном брендбуке.** Иные клиентские/HR материалы, печать, интеграция и production release не утверждены. Приложение не является редактором/CMS, не использует API и не содержит закрытых материалов. Библиотека `/brandbook/assets/` даёт три реальных download SVG из `public/downloads/` (wordmark для тёмного/светлого и отдельная X), без авторизации, без backend и без выдуманных форматов. Onest self-hosted из открытого пакета Fontsource (SIL OFL 1.1); не добавлять вручную бинарники из внутренних архивов. До выпуска проверенного полного пакета в HTML выставлен `robots: noindex, nofollow, noarchive` — **это не ограничение доступа**; после утверждения контентного состава решение об индексации пересматривается. Для клавиатуры предусмотрен переход к основному содержимому; копирование подписано как описание внешнего источника, а не официальная бренд-формулировка.

## Локальная разработка

`cd apps/brandbook && npm install && npm run dev`

Тесты: `npm test`. Сборка: `npm run build`.

## Источники и решения

Полная продуктовая спецификация находится в приватном `ideas/company-internal-services-81-2.4/services/brandbook/product/`. Специфика IRLIX, приватное исследование, реестр активов и вопросы — в `company/irlix/`. Не копировать приватные тексты в публичный репозиторий.

Сервис использует `UiAppShell` и `@irlix/ui`, не изменяет и не включает в себя `/design-system/`. Подготовлен для отдельного Docker image, Compose, CI и host nginx. Production rollout — по прямой команде владельца после проверки актуального CI, доступности и разрешённого контента. Разрешение на скачивание SVG не означает разрешение на сам rollout.
