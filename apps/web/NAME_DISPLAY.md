# Employees — отображение имени сотрудника

UI сервиса Employees использует два формата отображения имени:

- основной реестр `/employees/` показывает полное ФИО (`full_name`), включая отчество при наличии;
- все остальные ссылочные и заголовочные представления сотрудника показывают только `Фамилия Имя`.

Для второго варианта используется общий frontend-форматтер `shortEmployeeName` из `src/staffTree.js`. Он применяется в оргструктуре и подразделениях, карточках подразделений, селектах сотрудников, специальных ролях, журнале действий и заголовочных представлениях карточки сотрудника.

Полные кадровые данные не изменяются: `middle_name` сохраняется в модели и остаётся отдельным редактируемым атрибутом карточки сотрудника. API и БД продолжают хранить полное имя; сокращение выполняется только на уровне отображения.

Продуктовое правило зафиксировано в `ideas/company-internal-services-81-2.4/services/employees/NAME_DISPLAY.md`.
