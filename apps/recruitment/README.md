# Recruitment frontend

UI-MVP отдельного бизнес-контура Recruitment.

Реализованные маршруты:

- `/recruitment/` — обзор;
- `/recruitment/requests` — заявки руководителей и Recruitment;
- `/recruitment/candidates` и `/recruitment/candidates/:id` — база и карточка кандидата;
- `/recruitment/hiring` — hiring pipeline;
- `/recruitment/interviews` — интервью и feedback;
- `/recruitment/offers` — офферы;
- `/recruitment/talent-pools` — talent pools;
- `/recruitment/employment` — workflow трудоустройства;
- `/recruitment/onboarding` — onboarding;
- `/recruitment/tasks` — задачи;
- `/recruitment/analytics` — аналитика.

Текущий срез использует демонстрационные данные для проверки модели и UX. Следующий технический блок — Recruitment backend, persistence, permissions/scope и интеграции с Employees/Specialists.
