# Vacations frontend

Vue-интерфейс сервиса отпусков. Бизнес-правила и полный продуктовый сценарий хранятся в `ideas/company-internal-services-*/services/vacations/`.

## Реестры

### Мои отпуска

- строка отсутствия открывает карточку по клику;
- отдельная колонка «Документы» в реестре не отображается;
- контекстное меню `⋮` в строке не отображается, так как карточка доступна по клику на строку;
- прогресс согласований остаётся видимым в таблице.

### Управление отпусками

- строка отсутствия открывает карточку по клику;
- отдельная колонка «Документы» в реестре не отображается;
- в меню `⋮` не дублируются действия `Открыть`, `История` и `Документы`;
- в меню остаются только самостоятельные workflow-действия, доступные текущему пользователю.

## Карточка отсутствия

Карточка использует компактную двухколоночную подачу основных данных: название поля слева, значение справа. В основной блок входят период, длительность, статус, комментарий и документы. Документы не вынесены в отдельную крупную секцию; при наличии прав из поля можно скачать, удалить или загрузить файл.

Внизу карточки находится компактная история. В неё отдельными строками входят все сформированные approval tasks, включая несколько согласующих одного этапа. Для каждого шага показываются название этапа, конкретный согласующий и текущее состояние.

Если текущий пользователь должен выполнить конкретный pending approval task, кнопка `Согласовать` располагается прямо напротив этого шага. Для финального кадрового шага используется действие `Предоставить отпуск`. Эти действия не дублируются в верхнем меню карточки.

Обычные переходы статусов сохраняются в той же нижней истории отдельными строками с датой и причиной изменения.
