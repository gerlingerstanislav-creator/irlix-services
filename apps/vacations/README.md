# Vacations frontend

Vue-интерфейс сервиса отсутствий. Бизнес-правила и полный продуктовый сценарий хранятся в `ideas/company-internal-services-*/services/vacations/`.

## Навигация и верхняя панель

- основной пункт левого меню называется «Отсутствия»;
- отдельные заголовки страниц не используются: название текущего раздела показывает общая верхняя панель;
- кнопки и фильтры страниц выводятся в правой части верхней панели;
- верхняя панель прилегает к верхней границе окна без внешнего зазора.

## Реестры

### Отсутствия сотрудника

- строка отсутствия открывает карточку по клику;
- отдельная колонка «Документы» и контекстное меню в строке не отображаются;
- статус и индикаторы этапов объединены в одну колонку «Статус»;
- этапы показываются смысловыми иконками: завершённые зелёные, текущий жёлтый, ожидающие нейтральные; между этапами используется слабый пунктир;
- одинаковые этапы согласования используют одинаковую иконку.

### Управление отсутствиями

- отдельная колонка «Документы» не отображается;
- из меню исключены дублирующие действия `Открыть`, `История` и `Документы`;
- фильтр статусов содержит все рабочие статусы кроме `Запланировано`;
- статус и прогресс согласования отображаются в общей колонке.

## Карточка отсутствия

Верхняя часть карточки компактная и без декоративных разделителей. Заголовок «Карточка отсутствия» не показывается. Поля идут в порядке: период, статус, документы, комментарий.

Период отображается числовым форматом `1.01.2026 - 10.01.2026 (9дн.)`; длительность не выводится отдельной строкой. Статус отображается обычным текстом без цветной подложки. Для документа вместо исходного имени показывается действие `Скачать файл`.

Нижняя часть содержит единый список истории процесса. В него входят `Запланировано`, `Отправлено на согласование` (если этапы присутствуют у отсутствия) и все approval tasks. Пройденный этап показывает дату справа. Для текущего approval task там же показывается кнопка `Согласовать`, а для финального кадрового этапа — `Предоставить отпуск`. Отдельный второй журнал переходов статусов с датами в карточке не отображается.


### Отсутствия подразделения

- календарное отсутствие открывается кликом по любой части цветной полосы; отдельное меню `⋮` на полосе не показывается;
- начало и окончание каждого периода отмечаются скруглённым торцом и небольшим зазором, поэтому соседние отсутствия не сливаются визуально;
- цвета типов отсутствий приглушённые: оплачиваемый отпуск — синий; больничный и декрет — оранжевый; отгул и неоплачиваемый отпуск — серый;
- фамилии и имена в фиксированной левой колонке календаря отображаются обычным интерфейсным размером шрифта, сопоставимым с верхней панелью;
- выбор месяца выполняется через 12 карточек, аналогичных странице «Управление»: каждая карточка показывает месяц, процент отсутствий, часы отсутствий и общий фонд часов; прежний отдельный селектор месяца не используется.
