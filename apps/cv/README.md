# CV конвертер frontend

Первая итерация сервиса трансформации CV.

## Scope MVP

- отдельный route `/cv-converter/`;
- рабочий экран `/cv-converter/convert/`;
- загрузка PDF и DOCX drag&drop или через file picker;
- отображение исходного CV слева;
- преобразование извлечённого содержимого в тестовый шаблон `IRLIX Standard` справа;
- скачивание результата в DOCX и PDF;
- работа полностью в браузере без отправки содержимого CV в backend;
- единый `UiAppSidebar` и platform auth;
- PDF.js запускается через отдельный Vite Worker, без fake-worker dynamic import.

## Layout

- верхняя сервисная полоса содержит название `CV конвертер`;
- рабочая зона занимает оставшуюся высоту viewport;
- левая и правая области не выходят ниже окна браузера;
- исходник и результат прокручиваются независимо друг от друга.

## Ограничения первой итерации

- legacy `.doc` пока не разбирается: пользователь получает явное сообщение о необходимости сохранить файл как `.docx`;
- PDF без текстового слоя (scan) не распознаётся, OCR относится к следующей итерации;
- нормализация секций использует детерминированные заголовки/эвристики, LLM extraction пока отсутствует;
- шаблон один, клиентские привязки и API отсутствуют.

## Локальный запуск

```bash
npm install
npm run dev
```

При запуске всей платформы контейнер `cv-web` публикуется локально на `127.0.0.1:8096` и host nginx маршрутизирует `/cv-converter/` на него. Старый `/cv/*` перенаправляется на новый адрес.
